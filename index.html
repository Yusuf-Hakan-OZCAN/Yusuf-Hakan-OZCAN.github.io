Alfa-Beta budama

Minimax'ın oyun ağacındaki her dalı taraması gerekmez. Bir dalın sonucu, o ana kadar bulunmuş en iyi seçeneği zaten geçemeyecekse aramayı orada kesmek doğru cevabı değiştirmez — sadece işi kısaltır. Aşağıdaki iki break tam olarak bunu yapıyor ve bu yüzden algoritma aynı hamleyi çok daha az düğüm genişleterek buluyor.

alphabeta.py 
def alphabeta(board, depth, alpha, beta, maximizing):
    global node_count
    node_count += 1

    if depth == 0 or is_terminal(board):
        return evaluate(board), None

    best_move = None

    if maximizing:
        value = float('-inf')
        for move in get_possible_moves(board):
            child  = make_move(board, move, "X")
            result = alphabeta(child, depth - 1, alpha, beta, False)[0]
            if result > value:
                value = result
                best_move = move
            if value >= beta:
                break              # Beta kesme
            alpha = max(alpha, value)
        return value, best_move

Turing makinesinin geçiş fonksiyonu

Bir Turing makinesinin tüm davranışı δ: Q × Σ → Q geçiş fonksiyonunda saklıdır. Burada her durum yalnızca beklediği karakter sınıfını kabul ediyor, aksi halde doğrudan red durumuna düşüyor. Uzunluk için ayrı bir kontrol yok: yedi karakterden kısa girdi kabul durumuna hiç varamıyor, uzun girdi ise orada fazladan sembol görüyor.

tm_plaka.py 
def gecis(durum: str, sembol: str) -> str:
    """
    Geçiş fonksiyonu δ: Q x Σ -> Q.
    Her durum, sadece beklediği sembol sınıfını kabul eder;
    aksi halde qR (red durumu).
    """
    # q0, q1: rakam bekler
    if durum == "q0":
        return "q1" if sembol in RAKAMLAR else "qR"
    if durum == "q1":
        return "q2" if sembol in RAKAMLAR else "qR"

    # q2, q3: büyük harf bekler
    if durum == "q2":
        return "q3" if sembol in BUYUK_HARFLER else "qR"
    if durum == "q3":
        return "q4" if sembol in BUYUK_HARFLER else "qR"
